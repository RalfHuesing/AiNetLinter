# Relaunch-Diskussion

Für einen neuen Chat zuerst das unveränderte [Relaunch-Konzept](Relaunch-Konzept.md) als Motivation und dann das verbindliche [AiNetReview-Konzept mit DoD](AiNetReview-Konzept.md) lesen. Das zweite Dokument enthält alle aktuellen Produktentscheidungen und wird nach jeder inhaltlichen Klärung fortgeschrieben. Überholte Aussagen werden dort ersetzt; es gibt keine parallelen Entscheidungslisten.

Der Agent nennt bei Architekturfragen seine Empfehlung mit Begründung und weist auf Sackgassen hin. Er hält das Konzept bis zum definierten DoD vollständig: keine offenen Varianten, Platzhalter oder ungelösten Produktfragen. Eine Änderung der Empfehlung wird im Konzept nachgeführt. Das ursprüngliche Nutzerkonzept bleibt unangetastet. Diese README beschreibt ausschließlich den Gesprächs- und Dokumentationsablauf.
